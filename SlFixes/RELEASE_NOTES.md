# SCP SL Fixes 0.2.0

Adds ten configurable SUP crafting recipes for Items/Weapons 0.5.0: medical variants, Bio Grenade, Hacking Chip, reinforcement radio, SCRAMBLE, Volatile Pills and a rare railgun. Existing four recipes, Rough teleport and Core XP tracking remain. Recipe revision 1 migrates existing lists once, preserves explicit empty pools and respects later deliberate removal.

Crafting retains native bodies/serials, confirms provider adoption and shares normal provider supply. Recipe chances, settings and caps are editable; no new map/player roller is created. See docs/SUP_MIGRATION.md. Built for EXILED 9.15.2 / SCP:SL 14.2.8 with component auto-updates.

# Server playtest checklist

Build checks cannot verify client prediction, map collision or a real reinforcement wave. Use a separate test server on EXILED 9.15.2 / SCP: SL 14.2.8.

1. Install each DLL on its own. Then install all five. Verify the expected configuration section and a clean enable log. Remove Items or Weapons, restart, and confirm unavailable kits are excluded before selection while other eligible roles still work.
2. Try round start, escape, death, native zombie resurrection, role changes, disconnect/reconnect and round reset. Verify base factions, cards, scale, health and stamina. Confirm a revived zombie keeps its variant without rerolling; an enabled per-player burst cap must persist through resurrection.
3. With only `customitems.give`, run `ci give 7102` below 12 players: it must deliver without `--force` or another permission. Repeat after natural firearm supply is exhausted. With only `customitems.spawn`, repeat using `ci spawn`. Try `all`, multiple targets, full inventories, dead/restrained players and gas plus its paired filter. Results must count only actual deliveries. After admin grants, normal role kits/world loot must retain their original population/supply caps. A caller without the normal give/spawn permission must still be denied.
4. Fire all six Last Word shots. Attempt reload, unload, attachment changes, a drop, inventory swap and SCP-914 processing. No transfer should regenerate the six-shot budget, and SCP-914 should normalize it into a coin.
5. Test Nullifier against full shield, exact shield break, partial shield and no shield. Test humans with each armor type. Confirm each shot applies damage once and that armor/headshot handling remains native.
6. Shoot ordinary doors with Breach Shotgun. Count six shells across three firing cycles and verify no pellet double-counting. Test excluded gates, checkpoints, elevators, armories, locked objective doors and broken doors.
7. Throw each grenade beside a wall, closed door, another floor and an elevator. Smoke must render native SCP-244 fog from a flashbang body, with no primitives, flash, custom slow or health damage. Verify native cold does not drain HP/Hume shield and ordinary SCP-244 still behaves normally. Smoke uses native room/door boundaries; foam gameplay fields respect their configured room/cover rules. Check smoke visibility/client movement prediction at its edge and cleanup after its configured lifetime (20 seconds by default). Count exactly four physical child grenades at the parent explosion: each must launch upward/outward, bounce, use its own short fuse, and never split again. Clusters must never become native full-strength HE blasts or damage protected doors. Verify the combined 300 human / 1200 SCP damage cap across parent and children.
8. Have the thrower die or disconnect during a fuse. Verify the source faction remains the captured faction and that a new round cannot receive old delayed damage. Kill Explosive with a player, an environmental hazard and another corpse burst; each confirmed death qualifies with the new defaults; explicit death filters can exclude it.
9. Test the tool key and normal item controls. Verify an interrupted channel does not consume a supply. Test door brace removal by humans and SCPs, SCP-106 traversal, beacon scans, device destruction, chalk expiry, dressing and filter behavior. Confirm Maintenance Pass 7110 is absent from the registry even with old YAML item/role lists, cannot be given/spawned, and never appears in a Locksmith kit. Remaining items must retain their original IDs.
10. Use a jammer against SCP-079's ordinary door, room blackout, room lockdown and speaker actions. Existing locks must remain. Test room cooldown and the global active-device limit. Zone blackout is an explicitly unblocked action in this release.
11. Confirm Echo and Rattler sounds are spatial and readable. A beacon excludes its operator. A specimen heals only a consenting SCP-049-2 once per round; humans cannot use it as SCP-500. Test several players contesting the same specimen/device.
12. Flip normal coins with all effect weights zero, a one-use coin, a dropped coin, an inventory swap and a role-changing effect. The original coin serial must be consumed; the new held item must remain intact. Tagged chalk/brace coins must never trigger gambling effects. Repeat across two rounds to check spawn counters.
13. Test every experimental feature individually. Keep Redline's faster cadence out of scope until supported on the client. Verify Ricochet's single bounce, solid cover, armor, self-collision, headshot restriction and shooter attribution before enabling it in normal rounds.
14. Verify the role HUD on custom and ordinary human/SCP roles, then die, revive, escape and change roles. Confirm no stale role name survives. Select items and trigger combat warnings/CedMod hints; the HUD must yield and then resume. Check the default left-side column at 16:9, 16:10 and ultrawide resolutions. The full native/custom role name and wrapped description must stay together, with no orphan ROLE label at the crosshair or name at the bottom. Test `role_hud_side: Right`, edge padding, width and vertical offset; check that held weapons, health/stamina and CedMod overlays remain readable. Load an old config with the stock -11 offset and no layout revision: it must migrate to the new default. Set revision 1 and confirm deliberate custom offsets persist. Toggle the HUD off and unload Roles; other plugins' text must remain untouched.
15. Enable one updater at a time, then all five, with a read-only repository token in the server environment. Publish a higher matching component version through the release workflow. Confirm only its DLL changes, the backup matches the old file, running gameplay stays on its current assembly, and a full server restart loads the update. Check no-release/private-auth failure, incompatible game/framework, identical versions, bad checksum, invalid DLL, network interruption, and two server instances sharing one path. Disable a plugin during its request and verify cancellation. Confirm tokens never appear in YAML/logs and file permissions allow writing the plugin directory. Follow the rollback steps in `UPDATES.md` if needed.

Keep a record of server version, enabled entries, player count, cause of death, custom damage and exceptions. The initial rollout should use a smaller selection than the full catalog.

16. With `brainless.roles` alone, test `bprole`, `myrole`, `bprole <playerID>`, `bprole all`, and `bproles [playerID]`. Remove that permission and verify every command is denied; commands must be absent from the ordinary client console. Use `bprole set <roleID> <playerID>` to test every enabled profile, including equipment-dependent profiles, and inspect its confirmed state after the queued assignment. Disabled experimental profiles and missing providers must give a reason. Test a forced native role, a missed chance roll, depleted supply and no eligible profiles: the inspection reason should match. Confirm all default profile traits against `ROLE_STATUS.md`.
17. Give launcher 7207 and fire into players, empty space, props and doors: one native grenade per accepted shot, no hitscan damage, no launch through a muzzle-adjacent wall. Confirm the minimum interval, aim/physics/fuse and reduced 3.5m linear falloff. Fire all 16, then attempt a seventeenth, reload, unload, attachment swaps, shared 7.62 reserves, transfers and SCP-914. None may refill the launcher; SCP-914 must turn it into a coin. Check client ammo corrections while holding fire and prefer tap fire. Reset/unload Items or Weapons with grenades in flight; all owned projectiles/clouds must disappear without later native damage.

18. Test Locksmith without the Items DLL, then with all five. Assign D06, interact without a card at containment 1/2, armory 1/2, intercom, checkpoints and gates. Verify 15 seconds of progress, correct native gate/checkpoint opening, and a full 120-second cooldown starting only on success. Confirm containment 3, armory 3, mixed level-3 flags and parent checkpoint level-3 requirements are rejected. Change the requirement to level 3 mid-pick and confirm cancellation. Test ordinary locked doors, native lock state retention and another plugin denying the completion event: no falsely reported success or cooldown.
19. Interrupt a pick by damage, death, role change, restraint, leaving reach, cover, door opening or reset/unload. Retry and confirm a fresh 15 seconds with no spent cooldown. Complete a pick, then change role/reconnect/reassign D06: the remaining cooldown must persist until round reset. Repeated interaction must not restart the active timer or create parallel grants. A valid keycard must still open an accessible door immediately. Confirm progress yields to other hints, clears only its own hint, and the role HUD resumes.

20. Install only Brainless.ScpProximityChat.dll on the pinned EXILED/game build, then alongside the other plugins and CedMod. Confirm its SSS header/key/toggle-only/receive controls coexist with other settings for existing and late-joining clients. Check default N then normal Q, key release, duplicate key-state reports and F1 `.scpchat local/team/status`. Move two humans and two SCPs inside/outside 16m, through doors and between rooms/floors; verify directional falloff, no self echo, no double/global copy, no distant team listener and no spectator leakage while local. Team mode must restore native team voice. Confirm SCP-079/3114 native voice and SCP-939 mimicry are unchanged. Test server administrative/global mutes and another plugin denying sender/recipient events; none may produce custom audio. Test the SSS receive switch and individual `.scpchat mute/unmute <ID>` and `all` controls (scoreboard individual mutes alone do not cover speaker audio). Verify mute preferences survive a role/round change but reset on reconnect. Die, change roles, reconnect, reset and unload with live microphones; no stale speakers or global fallback should remain. Trigger Echo/Rattler audio simultaneously to check speaker-ID coexistence. Deliberately collide a setting ID and confirm only this plugin fails enable cleanly. Test its independent updater and rollback like the other components.

21. Assign Z04 with `bprole set Z04`, confirm with `bprole`, then die to gunfire, native explosions, Tesla/pits and self/environment damage. Each confirmed eligible death should produce one warning and one native blast, even after the player becomes Spectator or another zombie bursts. Cancel a Dying event from a test plugin: no burst. Check optional enemy-only/environment/explosion filters, zero/unlimited vs nonzero limits, cover, native friendly fire and SCP damage=0. Reset/unload with a pending burst: no later explosion. A role change without death must not burst.
22. Throw gas 7101 in multiple rooms and on stairs. With `debug: true`, confirm its log reports native emitter count, radius and duration. Check visible native fog, a 20% default human slow and no HP/shield/cold weapon penalty. Use a filter; slowing stops while smoke remains visible. Throw an ordinary SCP-244 nearby and overlap clouds: its cold mechanics and native immunity must remain. Test configured duration/radius/slows/DPS and room/cover/owner/allies rules. Native visuals have a prefab size limit described in TUNING.md. No gas primitive should exist; expiration/reset/unload must clear emitters and movement layers.
23. Give impact 7113. Throw against walls, floor, ceiling, doors, moving objects and players. Check the 0.1s arming delay, ignored thrower collisions, one explosion per projectile and continued contact after arming. Toggle player impact mode. An airborne grenade must expire at its safety fuse. Check damage/radius/cover, canceled native detonation, and cleanup on round reset/unload. Ordinary HE grenades must keep their normal fuse.
24. Change cluster count, child fuse/stagger, launch speeds, radius, damage and shared caps; reload Items and throw a new cluster. Default remains four physical children at 120/300 center damage and 5.5m radius, a 180/500 parent over 6m, and shared 300/1200 raw damage caps. Extra children cannot exceed the configured shared cap, even across overlapping detonations. A zero cap means zero damage. No child recursively becomes a cluster.
25. Test all three reload commands with the correct CedMod nodes and without them. Test default combined YAML and EXILED separated configs. Invalid YAML, null sections, NaN/infinity, invalid counts, duplicate IDs/names, native body/registration changes and an external CustomItems name collision must reject without replacing active settings. Reload with fields, devices, finite guns, supply use and lockpick cooldowns active: state must not reset/refill. New grants/throws use the new values. Full restart applies intended registration changes. Tune launcher magazine to 24: a newly granted weapon has 24 shots while an older partially spent 16-shot instance keeps its remaining budget. Recheck SCP-914/drop/transfer/reload/attachments.

26. Start with the updated Items/Weapons and existing YAML missing `distribution`: confirm new defaults appear and work without deleting old configs. With debug enabled and forced 100% test chances, verify native map and locker conversions, one bundle per room/provider, per-round limits, enabled/disabled content and shared supply after role kits. No keycard/objective/ammo/SCP item should be replaced by the default pools. Later player drops/death loot/914 products must not become fresh map-roll targets. A map reload must not reroll existing pickups. Verify source-body/zone filters and custom item exclusion.
27. Open normal and first-open/deferred locker chambers after conversion. Position, native access/locks and serial tracking must remain. A converted gas grenade's filter must stay with the same chamber, remain inaccessible until its native opening, and appear on opening. Exhaust filter supply and verify the HE remains vanilla with no spent gas award. Test unknown locked/deferred loose gas anchors: paired conversion should skip. Extra world loot must use loose accessible anchors, respect room caps and stop with insufficient supply; disabling `world_loot` must leave replacement/player switches independently functional.
28. Test Class-D, Scientist, Guard and reinforcement spawning with native and custom kits. Wait the configured 0.75/1s delay; eligible players should get at most one item/conversion, with no duplicate callback rolls, no free reserve on a converted firearm, no custom-gear overwrite and no full-inventory deletion. Gas needs filter space. Die/reconnect/respawn after an award: the per-user round limit persists. Escape/force-class/SCP revival must not roll with default reasons. Change role or disconnect while a grant is pending: no stale grant. Reset/unload/reload while callbacks are queued and confirm safe cancellation/state retention.
29. With the role HUD active, toggle SCP nearby mode using N and confirm the exact enabled message is visible. Toggle back for the disabled message; repeat key release/repeated reports and `.scpchat local/team`. The role HUD must resume after the configured hint duration. Exhaust speaker channels: show failure, retain team mode and never show the enabled message. Check configurable texts, 0.5-10s duration, `show_hints: false`, and existing personal/global mute behavior.

30. Test Impact, Cluster, launcher grenades and Z04 against an enemy with god mode off and after spawn protection expires. Verify native Hurting events receive positive explosion damage with penetration 50, correct attacker attribution, expected armor/shield behavior and no huge world-coordinate force. Check cover at walls/doors and loose pickup/ragdoll bodies. Cluster parent must damage once and launch exactly four children; parent and children share 300/1200 raw caps. Test each configurable penetration value including invalid zero, zero-damage disable fields, late hurt cancellation and custom damage multipliers. Load old stock grenade YAML with revision missing/0: active defaults should migrate. Set Items revision 2 / Weapons revision 1 and deliberately keep old values: they must persist. Confirm customized values/counts survive migration. Gas remains non-damaging by default.

31. Install chat 0.1.2 over old YAML with `default_hold_mode: true` and a client that previously selected Hold. Confirm the mode control disappears, N tap enables nearby and release/repeated reports do not disable it. Check enabled/disabled hints, two living players, normal voice transmission, existing receive/mute controls and native global/server mutes. Trigger a speaker-allocation failure: mode must remain team, no enabled hint, and duplicate key-down reports must not retry/spam. Use `.scpchat status` counters to distinguish missing voice input, rejected recipients and transmitted audio; verify actual client playback separately.
32. Install Roles 0.2.3, Items/Weapons 0.3.1, BetterCoinflips 5.1.4 and chat 0.1.3 with no host environment token. Put a valid read-only token directly into each plugin's `auto_update.token`, fully restart and confirm each updater can read its private releases. Repeat with an empty config token and the old environment setup; config credentials must win when both are set. Empty credentials must explain `auto_update.token`; inaccessible credentials must explain repository permissions. No token or HTTP response body should appear in updater logs, and failed checks must leave the active DLL untouched.
32. Assign S04 with an empty old allowlist. Confirm a native SCP-330 bag with exactly three standard candies and no substituted painkillers. Set counts 1/6 and explicit registered colors, reload and reassign; check exact counts, no extra seed candy and expected native consumption/effects. Test unsupported colors, empty registries, full inventory and bag-add failure; no medicine fallback or false successful profile. Check the Child candy path also receives real candy and that unrelated configured role kit items remain unchanged.

33. Load Items 0.3.2 with old Door Brace 7105 coin YAML and catalog revision 1. Confirm `ci give 7105` and natural grants/replacements produce a keycard, ordinary door interaction jams it after the configured channel, charges/removal/expiry/cuffed checks still work, and restricted doors cannot gain access. Verify old coin-only 7105 map/loadout rules migrate without touching chalk or empty/edited pools. Test louder Echo, jammer, brace, beacon, Rattler, vent and ricochet sounds at 1/6/12m. Compare SCP nearby voice at the same distances with two living clients and the same client audio settings; directional falloff, range, mute and team controls must remain intact. Adjust gain if client clipping is audible. Confirm custom settings survive audio migration and marker 1 retains deliberately old values. For clusters, count four separated child launches and compare damage at 0/3/5m, armor, cover, shared caps, custom overrides and revision-1 upgrades.

34. Install current Roles/Items/Weapons plus Core and SlFixes on the pinned framework. Inspect G01's actual card: 1 containment, 2 armory, 1 administration, no accidental intercom/gate level increase. Test `bprole set Z04`, `bprole set explosive_zombie` and explicit player IDs with permission checks. Smoke 7101 must be a flashbang, emit full-size native SCP-244 fog for its configured lifetime, produce no blinding/bang/damage/custom slow/filter, and clean up on expiry/round/disconnect/unload. Ordinary SCP-244 and optional filter behavior must be checked separately. Fire all 16 launcher rounds at native cadence: exactly one projectile per approved bullet, none on a denied/empty/duplicate callback, no reserve/reload/unload/refill, and configured capacity above 16 must clamp.
35. Test Rough teleports with different physical roles, occupied rooms, closed doors, pits, decontaminated LCZ and no safe destination. Native cancellations must win; teleports must not send players to Surface/Pocket or unsupported floor/headroom. Test each dropped/inventory recipe, full inventory, zero chance/cap, missing/disabled providers, normal supply/population denial and existing custom items. Successful conversion must retain serial and spend normal supply once; failure must permit the native result without duplicating/consuming input.
36. Confirm XP only for real rounds/eligible confirmed actions: enemy human/SCP kills, deaths, escapes, crafts, rough teleports and round participation/survival. Test self/friendly kills, spectators, duplicate callbacks, short rounds, reward caps, reconnects and tuning reload. Restart and confirm XP/counters/Discord links persist; corrupt a copy of stats.json and verify backup recovery without erasing files. With Core absent, gameplay features and standalone updates must remain available. Test all seven published DLL/manifest checks and Core updater ownership with per-plugin/global credentials.
37. With your own Discord application/token and guild, enable Core's bot and verify gateway connection/heartbeat/reconnect, three slash commands, code expiry/cooldown/replay prevention and persisted links. No token, interaction token, headers or response bodies should appear in logs; ordinary nicknames must not ping users or inject output lines. Replies should be private. Exercise commands during automatic saves and gateway reconnects; gameplay must not block. No external Discord connectivity has been claimed from headless checks.

## SUP content regression playtest

38. Give 7114–7117, 7119–7122 and 7208 with `sci give`/`ci give`. Verify actual receipt and disabled-content handling. Test legacy 101–112 mapping; 103 must give Anti-096.
39. Use each pill; interrupt channels by movement/item/role/damage, test untargeted Anti-096 retention, all-096 removal, optional immunity, seven-second stealth refresh, native 939 target suppression, attack break and once-per-round reset.
40. Toggle SCRAMBLE, hold another item, look at 096, damage him, transfer/drop/reacquire the goggles, exhaust the battery and change role. Protection must apply only to visual acquisition, never clear an existing target or refill an exhausted serial.
41. Throw two Bio Grenades. Check independent fog lifetimes, exposure resets on leaving, filter, wall/room restrictions, once-per-cloud corrosion, SCP/owner settings and optional heal/AHP pulses.
42. Hack a level-two door; test level-three in each access category, gates, elevators, hard locks, disabled checkpoints, door changes and aiming away before completion. Failed channels must retain the chip.
43. Call radio reinforcements on each faction with different spectator counts. Reject Class-D/SCP/Overwatch, verify earliest-time/call/cooldown limits, arrivals never replace live players or force a full wave, and restart cancels pending calls.
44. Use Volatile Pills with survival chance temporarily 100 then 0. Owner survival must match the roll, blast must respect friendly fire/cover, role changes must not kill a later life, and no duplicate native blast damage should occur.
45. Charge railgun, cancel by switching/dropping/dying, transfer it and try ordinary reload/unload/attachments. Only completed shots consume finite charges. Verify targets behind shooter or beyond walls take no beam damage, allies/god mode follow policy, impact damage is separate, and effects disappear on reset.
46. Fire launcher to 16 and try a seventeenth shot. Test empty disposal on/off and rapid item switching/drop at the last shot; another weapon must never be removed and pickup must never refill.
47. Enable individual item files, edit damage/counts and reload. Restart must preserve byte-for-byte file edits. Invalid YAML/IDs/registration edits must retain active settings; disabled per-item mode must use main YAML again.

## Infection and updater compatibility

48. Install Round Events, grant `projectbrainless.events`, and run `bpevent infection next` with at least four living players. Check starting seed limits, fresh survivor kits, low HP/zero shields and status counts.
49. Kill a survivor with native 3114 slap and strangulation. Confirm exactly one conversion at the pre-death point with reduced health. Repeat with newly converted skeletons.
50. Test falls/Teslas/decontamination/warhead, poison, firearms, explosives credited to SCP players, other SCPs and infected deaths: none may infect. Cancel a Dying event and confirm no conversion.
51. During the conversion delay, disconnect, force-class, stop the event and restart the round. Old callbacks must never overwrite a later life. Check last-human deaths hold round end until conversion completes.
52. Check normal and radio reinforcement blocking, late-join policy, survivor friendly fire, disguise blocking/opt-in, human/infected wins, draw, round lock and stop cleanup. Actual client placement, strangle attacks and summary are live checks.
53. Replace all updater DLLs manually once, including Core if present. Keep YAML, regenerate any exposed token and check for a successful update/no-new-release message. Induce bad access and confirm sanitized HTTP errors. Do not post credentials.
54. Inspect every role/item/weapon tooltip and role HUD with old YAML/per-item files. Descriptions should explain abilities briefly, without config/prototype/native-body placeholders. Short custom gameplay text should remain.

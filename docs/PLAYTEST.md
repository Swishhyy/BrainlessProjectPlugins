# Server playtest checklist

Build checks cannot verify client prediction, map collision or a real reinforcement wave. Use a separate test server on EXILED 9.15.2 / SCP: SL 14.2.8.

1. Install each DLL on its own. Then install all four. Verify the expected configuration section and a clean enable log. Remove Items or Weapons, restart, and confirm unavailable kits are excluded before selection while other eligible roles still work.
2. Try round start, escape, death, native zombie resurrection, role changes, disconnect/reconnect and round reset. Verify base factions, cards, scale, health and stamina. Confirm a revived zombie keeps its variant without rerolling or regaining a corpse burst.
3. With only `customitems.give`, run `ci give 7102` below 12 players: it must deliver without `--force` or another permission. Repeat after natural firearm supply is exhausted. With only `customitems.spawn`, repeat using `ci spawn`. Try `all`, multiple targets, full inventories, dead/restrained players and gas plus its paired filter. Results must count only actual deliveries. After admin grants, normal role kits/world loot must retain their original population/supply caps. A caller without the normal give/spawn permission must still be denied.
4. Fire all six Last Word shots. Attempt reload, unload, attachment changes, a drop, inventory swap and SCP-914 processing. No transfer should regenerate the six-shot budget, and SCP-914 should normalize it into a coin.
5. Test Nullifier against full shield, exact shield break, partial shield and no shield. Test humans with each armor type. Confirm each shot applies damage once and that armor/headshot handling remains native.
6. Shoot ordinary doors with Breach Shotgun. Count six shells across three firing cycles and verify no pellet double-counting. Test excluded gates, checkpoints, elevators, armories, locked objective doors and broken doors.
7. Throw each grenade beside a wall, closed door, another floor and an elevator. Gas must render native SCP smoke with no primitives, no health damage and a 20% slow only while eligible humans remain inside; filters remove the custom slow but not world smoke. Verify native cold does not drain HP/Hume shield and ordinary SCP-244 still behaves normally. Gas/foam gameplay effects must stay in the origin room and respect cover. Check smoke visibility/client movement prediction at its edge and cleanup after eight seconds. Count exactly four physical child grenades at the parent explosion: each must launch upward/outward, bounce, use its own short fuse, and never split again. Clusters must never become native full-strength HE blasts or damage protected doors. Verify the combined 75 human / 200 SCP damage cap even when all four overlap.
8. Have the thrower die or disconnect during a fuse. Verify the source faction remains the captured faction and that a new round cannot receive old delayed damage. Kill Explosive with a player, an environmental hazard and another corpse burst; only its eligible enemy combat death may arm it.
9. Test the tool key and normal item controls. Verify an interrupted channel does not consume a supply. Test door brace removal by humans and SCPs, SCP-106 traversal, beacon scans, device destruction, chalk expiry, dressing and filter behavior. Maintenance Pass must open ordinary permitted containment-level-1 doors immediately and repeatedly, including native thrown-card interactions. It must obey locks and deny checkpoints, gates and armories. Put the pass through SCP-914 both held and dropped; verify the Janitor normalization plus native recipe.
10. Use a jammer against SCP-079's ordinary door, room blackout, room lockdown and speaker actions. Existing locks must remain. Test room cooldown and the global active-device limit. Zone blackout is an explicitly unblocked action in this release.
11. Confirm Echo and Rattler sounds are spatial and readable. A beacon excludes its operator. A specimen heals only a consenting SCP-049-2 once per round; humans cannot use it as SCP-500. Test several players contesting the same specimen/device.
12. Flip normal coins with all effect weights zero, a one-use coin, a dropped coin, an inventory swap and a role-changing effect. The original coin serial must be consumed; the new held item must remain intact. Tagged chalk/brace coins must never trigger gambling effects. Repeat across two rounds to check spawn counters.
13. Test every experimental feature individually. Keep Redline's faster cadence out of scope until supported on the client. Verify Ricochet's single bounce, solid cover, armor, self-collision, headshot restriction and shooter attribution before enabling it in normal rounds.
14. Verify the role HUD on custom and ordinary human/SCP roles, then die, revive, escape and change roles. Confirm no stale role name survives. Select items and trigger combat warnings/CedMod hints; the HUD must yield and then resume. Check several client resolutions and adjust `role_hud_vertical_offset` if necessary. Toggle the HUD off and unload Roles; other plugins' text must remain untouched.
15. Enable one updater at a time, then all four, with a read-only repository token in the server environment. Publish a higher matching component version through the release workflow. Confirm only its DLL changes, the backup matches the old file, running gameplay stays on its current assembly, and a full server restart loads the update. Check no-release/private-auth failure, incompatible game/framework, identical versions, bad checksum, invalid DLL, network interruption, and two server instances sharing one path. Disable a plugin during its request and verify cancellation. Confirm tokens never appear in YAML/logs and file permissions allow writing the plugin directory. Follow the rollback steps in `UPDATES.md` if needed.

Keep a record of server version, enabled entries, player count, cause of death, custom damage and exceptions. The initial rollout should use a smaller selection than the full catalog.

16. With `brainless.roles` alone, test `bprole`, `myrole`, `bprole <playerID>`, `bprole all`, and `bproles [playerID]`. Remove that permission and verify every command is denied; commands must be absent from the ordinary client console. Use `bprole set <roleID> <playerID>` to test every enabled profile, including equipment-dependent profiles, and inspect its confirmed state after the queued assignment. Disabled experimental profiles and missing providers must give a reason. Test a forced native role, a missed chance roll, depleted supply and no eligible profiles: the inspection reason should match. Confirm all default profile traits against `ROLE_STATUS.md`.
17. Give launcher 7207 and fire into players, empty space, props and doors: one native grenade per accepted shot, no hitscan damage, no launch through a muzzle-adjacent wall. Confirm the minimum interval, aim/physics/fuse and reduced 2.5m linear falloff. Fire all 16, then attempt a seventeenth, reload, unload, attachment swaps, shared 7.62 reserves, transfers and SCP-914. None may refill the launcher; SCP-914 must turn it into a coin. Check client ammo corrections while holding fire and prefer tap fire. Reset/unload Items or Weapons with grenades in flight; all owned projectiles/clouds must disappear without later native damage.

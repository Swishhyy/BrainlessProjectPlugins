# Project Brainless — BetterCoinflips

Configured random outcomes when players flip ordinary coins.

**Install:** fully stop the server, put `BetterCoinflips.dll` in `EXILED/Plugins`, then start it. Target: EXILED 9.15.2 / SCP:SL 14.2.8. Each plugin is optional and builds separately. No peer plugin DLL is required for loading.

**Config:** `better_coinflips`. Keep your existing YAML when updating.

**Commands:** `getserial [playerID]` · `coinuses get player [playerID]`
